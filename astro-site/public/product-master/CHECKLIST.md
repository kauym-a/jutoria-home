# JUTORIA — ছবি আপলোডের জন্য প্রস্তুত ফোল্ডার তালিকা

মোট 30টা প্রোডাক্টের জন্য ফোল্ডার তৈরি হয়েছে `public/product-master/` এর ভেতরে — ছবি ছাড়া বাকি সব তথ্য (SKU, ক্যাটাগরি, স্পেসিফিকেশন) ইতিমধ্যে সিস্টেমে আছে।

## কীভাবে ব্যবহার করবেন

1. নিচের তালিকা থেকে একটা প্রোডাক্ট বেছে নিন
2. তার ফোল্ডারে (`public/product-master/<folder>/`) গিয়ে ছবি তুলে রাখুন — নামকরণ নিয়ম ও বিস্তারিত সেই ফোল্ডারের `info.txt`-এ আছে
3. `/admin/products` -> প্রোডাক্টটা Edit করুন -> Images যোগ করুন -> Description লিখুন -> Save করলেই লাইভ
